# Atlas

Atlas is an experimental investment portfolio management application built
using a multi-agent software engineering workflow.

## Purpose

The primary goal of this repository is to explore agentic software development,
including:

- multi-agent orchestration;
- autonomous implementation;
- independent code review;
- automated testing;
- Git-based collaboration;
- shared project documentation;
- human supervision.

## Status

Experimental / educational project.
